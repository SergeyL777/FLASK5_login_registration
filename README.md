# Блог достижений программиста

Веб‑приложение для ведения дневника программиста с авторизацией и персональными заметками.

## Функциональность

Приложение позволяет:
* регистрироваться и входить в систему;
* создавать и просматривать персональные заметки (дневник программиста);
* отслеживать прогресс обучения в виде таблицы;
* просматривать информацию о пользователе (страница «Обо мне»);
* переходить между разделами сайта через навигационное меню.

## Технологии

* **Flask** — веб‑фреймворк;
* **Flask‑SQLAlchemy** — ORM для работы с БД;
* **Flask‑Migrate** — управление миграциями базы данных;
* **SQLite** — база данных;
* **HTML/CSS** — разметка и стилизация;
* **Jinja2** — шаблонизатор.

## Модели данных

### Таблица `users`
* `id` (Integer, PK) — уникальный идентификатор;
* `username` (String) — имя пользователя (уникальное);
* `email` (String) — email (уникальный);
* `password_hash` (String) — хешированный пароль;
* `token` (String) — токен авторизации (уникальный);
* `token_expiry` (DateTime) — срок действия токена.

### Таблица `notes`
* `id` (Integer, PK) — уникальный идентификатор;
* `title` (String) — заголовок заметки;
* `subtitle` (String) — подзаголовок;
* `text` (Text) — текст заметки;
* `user_id` (Integer, FK) — ссылка на пользователя (связь один‑ко‑многим).

### Предварительные требования

* Установленный **Python 3.8+**;
* установленный **pip** (менеджер пакетов Python);
* установленный **Git** (опционально, для клонирования).
