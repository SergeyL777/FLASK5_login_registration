# Flask-приложение «Дневник программиста»

Веб‑приложение на Flask с интеграцией базы данных для ведения дневника программиста. Позволяет добавлять, просматривать и хранить заметки с заголовком, подзаголовком и текстом.

## Цель проекта
Научиться работать с базами данных в Flask для увеличения функциональности веб‑приложения.

## Функциональность
* Добавление новых записей в дневник через веб‑форму.
* Просмотр всех записей на странице «Дневник программиста».
* Хранение данных в SQLite‑базе данных.
* Поддержка миграций базы данных через Flask‑Migrate.
* Автоматическая инициализация БД и добавление тестовой записи при первом запуске.

## Технологии

* **Python** — язык программирования;
* **Flask** — микрофреймворк для веб‑приложений;
* **HTML5** — разметка веб‑страниц;
* **CSS3** — стилизация интерфейса;
* **Git** — контроль версий;
* **GitHub** — хостинг кода.
